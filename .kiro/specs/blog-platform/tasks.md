# Implementation Plan: Blog Platform

## Overview

Implement a full-stack Blog Platform using Next.js 14 (App Router), TypeScript, MongoDB/Mongoose, JWT authentication, TipTap rich text editor, Cloudinary image uploads, and Tailwind CSS. Tasks are ordered to build incrementally: project scaffolding → data layer → auth utilities → validation/sanitisation → API routes → middleware → frontend components → pages → tests.

## Notes

- Tasks marked with `*` are optional and can be skipped for faster MVP delivery
- Property-based tests use **fast-check** with a minimum of 100 runs per property (`{ numRuns: 100 }`)
- Integration tests use **mongodb-memory-server** to spin up an in-memory MongoDB instance — no external DB required
- Each property test MUST include a comment in the format: `// Feature: blog-platform, Property {N}: {property_text}`
- All 21 correctness properties from the design document are covered by test sub-tasks
- The `sanitiseHTML` utility must be called server-side before persisting any rich text content
- The `connectDB()` utility must be called at the top of every API route handler before any Mongoose operation
- Image uploads default to local filesystem when `CLOUDINARY_URL` is not set — suitable for local development
- The `x-user-id` and `x-user-role` headers are set by middleware and must never be trusted from the client directly
